# The One-Line Laugh

One original funny line about hiring an AI to do your job — and
spending all day explaining your job to the AI instead.

> I hired an AI to do my job, and now I spend all day explaining my job to the AI, which is somehow still my job.

## Run

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
